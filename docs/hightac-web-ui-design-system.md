# HighTac Web 管理台 UI 设计规范

## 1. 设计来源

本规范服务于 HighTac 局域网声光寻物管理台。用户指定的 `Magic Slide`
skill 在当前 Codex 环境中不可用，因此实现阶段使用本机
`brand-design-md` skill 获取 `nvidia` 的 `DESIGN.md`，并将其中可复用的
设计语言转换为 HighTac 自有管理后台规范。

只参考视觉语言，不使用 NVIDIA 的名称、Logo、字体文件、图片或其他品牌素材。
界面必须首先是一套高密度、可重复操作的工业管理工具，而不是营销网站。

## 2. 设计原则

- 黑色与石墨色用于固定导航和关键状态面板，白色用于表格和表单工作区。
- `#76B900` 只用于主操作、选中态、在线强调和焦点，不作为大面积背景。
- 所有交互表面保持锐利，常规圆角为 `2px`，任何业务卡片不超过 `8px`。
- 使用边框和背景分区建立层级；常规卡片不使用投影。
- 不使用渐变、光球、模糊装饰、巨型 Hero 或卡片嵌套。
- 页面按“筛选区 -> 工具栏 -> 数据表格 -> 分页/抽屉详情”组织。
- 状态不能只依赖颜色，必须同时显示文字和图标。

## 3. Design Tokens

### 3.1 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-primary` | `#76B900` | 主按钮、选中态、焦点框 |
| `--color-primary-active` | `#5A8D00` | 按下态 |
| `--color-nav` | `#000000` | 左侧导航、顶部品牌区 |
| `--color-nav-elevated` | `#1A1A1A` | 导航分组、深色状态区 |
| `--color-canvas` | `#FFFFFF` | 主工作区 |
| `--color-surface-soft` | `#F7F7F7` | 筛选区、次级表面、交替行 |
| `--color-border` | `#CCCCCC` | 卡片、表格和输入框边界 |
| `--color-border-strong` | `#5E5E5E` | 深色表面分隔线 |
| `--color-text` | `#1A1A1A` | 正文 |
| `--color-text-muted` | `#757575` | 辅助信息 |
| `--color-success` | `#3F8500` | 在线、成功 |
| `--color-warning` | `#DF6500` | 待确认、低电量 |
| `--color-error` | `#E52020` | 离线、失败、危险操作 |
| `--color-info` | `#007C91` | 运行中、连接中、信息状态 |

状态色仅用于状态标签、图标、趋势和确认信息，不替代品牌主色。

### 3.2 字体

使用 `Inter, "Noto Sans SC", "Microsoft YaHei", Arial, sans-serif`。不分发
NVIDIA 专有字体。全局字间距为 `0`。

| 角色 | 字号/行高 | 字重 |
| --- | --- | --- |
| 页面标题 | `24px / 30px` | `700` |
| 区块标题 | `18px / 25px` | `700` |
| 卡片标题 | `16px / 24px` | `700` |
| 正文/表格 | `14px / 22px` | `400` |
| 按钮 | `14px / 20px` | `700` |
| 辅助文本 | `12px / 18px` | `400` |

管理台内不使用随视口缩放的字体。数值统计可使用 `28px / 36px`，但不得挤压
操作区或表格。

### 3.3 间距和形状

- 基础间距：`4px`；常用节奏：`4/8/12/16/24/32px`。
- 页面内容边距：桌面 `24px`，窄屏 `16px`。
- 表格行高：默认 `48px`，紧凑模式 `40px`。
- 按钮和输入框高度：`40px`，关键主操作可为 `44px`。
- 普通圆角：`2px`；抽屉、对话框和大面板最大 `6px`。
- 边框：`1px solid var(--color-border)`。

## 4. 应用框架

- 桌面端采用固定深色左侧导航，展开宽度 `232px`，折叠宽度 `64px`。
- 顶部栏高度 `56px`，显示面包屑、实时连接状态和管理员菜单。
- 主内容区域最大宽度不做营销式限制；数据表应充分利用可用宽度。
- `<= 1024px` 时导航默认折叠；`<= 768px` 时变为抽屉导航。
- 手机和平板可查询状态；复杂批量操作在窄屏中使用全屏抽屉。

导航顺序：仪表盘、MQTT 服务、基站管理、灯条管理、产品与绑定、Android
设备、操作记录、系统设置。

## 5. 组件规范

### 5.1 按钮和图标

- 每个命令按钮使用 `lucide-react` 图标；常见动作可只显示图标并提供 Tooltip。
- 同一可视区域最多一个实心绿色主按钮，其余使用边框或文本按钮。
- 停止、解绑、撤销和恢复等危险操作使用红色，并要求确认对话框。
- 启动、停止、重启必须显示进行中和不可重复提交状态。
- 图标按钮稳定为 `40x40px`，内容变化不能引发布局位移。

### 5.2 状态标签

- 在线：绿色圆点 + `在线`。
- 运行中/连接中：青色图标 + `运行中` 或 `连接中`。
- 待确认/低电量：橙色图标 + 对应文字。
- 离线/异常/失败：红色图标 + 对应文字。
- 未知/已停止：灰色图标 + 对应文字。

标签使用 `2px` 圆角，不使用胶囊形状。

### 5.3 表格、筛选和详情

- 2000 条灯条使用服务端分页，分页规格为 `20/50/100`。
- 筛选项保持一行优先，空间不足时自然换行，不遮挡工具栏。
- 关键 ID、产品编码和时间列禁止省略到无法区分；可复制完整值。
- 行操作优先使用图标按钮和更多菜单，避免一行堆放多个文字按钮。
- 详情使用右侧抽屉，不在表格内嵌套卡片。

### 5.4 数据卡片和图表

- 仪表盘卡片只用于独立 KPI 或异常队列，使用 `1px` 边框和 `2px` 圆角。
- 卡片左上可使用 `8x8px` 绿色方块作为 HighTac 技术感标识。
- Recharts 图表使用绿色主序列，橙/红/青表达语义，不使用同色深浅堆叠。
- 图表必须有空数据、加载和失败状态。

## 6. 页面要求

- 登录：黑色全高背景中的单一登录面板；显示 HighTac 平台名，不使用营销文案。
- 仪表盘：服务健康、Broker、基站、灯条、绑定、命令和设备状态一屏可扫读。
- MQTT 服务：三层检查（Windows 服务、TCP、后台 MQTT）、控制按钮和有界日志。
- 基站/灯条：高密度表格、状态筛选、低电量/异常快捷视图和抽屉详情。
- 产品与绑定：产品、绑定两个视图；支持扫码枪输入、绑定/重绑、批量亮灭灯和
  Excel 预检后整体提交。
- 操作记录：按时间、操作者、动作、实体和结果筛选，可导出。
- 系统设置：站点网络、Android 审批、备份恢复和管理员安全按标签页组织。

## 7. 验收

- Playwright 检查 `1440x900`、`1920x1080`、`1024x768` 和 `390x844`。
- 页面无横向意外滚动、文字遮挡、按钮截断或状态重叠。
- 键盘可到达全部交互控件，焦点使用 `#76B900` 的清晰轮廓。
- 正文和控件达到 WCAG AA 对比度；图表和状态不只依赖颜色。
- 截图中不存在渐变、装饰光斑、营销 Hero、卡片嵌套或大于 `8px` 的业务卡片圆角。
